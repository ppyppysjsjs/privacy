《轮回修仙》隐私政策

轮回修仙 · 肉鸽增量修仙游戏

生效日期：2026年11月19日 更新日期：2026年11月19日 版本：v1.0 适用版本：Android 1.30

本游戏不收集你的任何个人信息

《轮回修仙》是一款完全单机的游戏。它不需要注册账号、不联网、不含广告、不含任何第三方统计或广告 SDK，也不会读取你的设备标识、位置、通讯录、相册或麦克风。游戏进度全部保存在你自己的设备上。

一、适用范围与运营者

本政策适用于由 江邕工作室（以下简称"我们"）开发并发布的移动端游戏《轮回修仙》（应用包名 com.yg.samsara，以下简称"本游戏"）。

本政策说明本游戏如何处理与你的个人信息相关的事项。我们依据《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》《信息安全技术 个人信息安全规范》等法律法规制定本政策。

请在使用本游戏前阅读本政策。你开始使用本游戏，即表示你已理解并同意本政策。

二、我们不收集任何个人信息

本游戏不收集、不存储、不上传任何可识别你个人身份的信息。具体而言：

信息类别是否收集说明
姓名、手机号、邮箱、身份证号不收集本游戏没有账号系统，无需注册或登录
设备标识符（IMEI / Android ID / OAID / IDFA 等）不收集不读取任何设备唯一标识
地理位置不收集未申请定位权限
通讯录、短信、通话记录不收集未申请相关权限
相册、相机、麦克风不收集未申请相关权限
已安装应用列表不收集未申请相关权限
网络行为、浏览记录不收集本游戏未申请网络权限，无法联网
支付与交易信息不收集本版本不含任何内购项目

由于本游戏不具备联网能力，上述任何数据在技术上都不可能被传输至我们的服务器或任何第三方。

三、游戏数据保存在哪里

游戏运行过程中会产生存档数据，包括修行进度、角色属性、功法与装备、洞府状态、游戏设置等。这些数据的处理方式如下：

  • 存储位置：仅保存在你设备的应用私有目录（Android 系统路径 /data/data/com.yg.samsara/files/），该目录其他应用无法访问；
  • 存储形式：本地 JSON 存档文件，不加密、不含任何个人信息字段；
  • 是否上传：不上传。本游戏没有网络权限，不存在上传通道；
  • 是否共享：不共享。我们无法访问这些文件；
  • 删除方式：在系统设置中清除本游戏数据，或卸载本游戏，存档即被系统永久删除，我们无法恢复，也无从备份。

四、设备权限说明

本游戏在 Android 系统中仅声明并申请一项权限：

权限用途是否必需
WAKE_LOCK（保持屏幕唤醒）在挂机修行等长时间运行场景中防止屏幕自动熄灭，保证游戏正常推进是

该权限不涉及个人信息，也不会读取或传输任何数据。你可以在系统「设置 → 应用 → 轮回修仙 → 权限」中查看该权限。

本游戏未申请以下任何权限：网络访问、存储读写、位置信息、通讯录、短信、相机、麦克风、读取应用列表、读取设备标识等。

五、第三方 SDK 与外部服务

本游戏未集成任何第三方 SDK。包括但不限于：

  • 统计分析类 SDK（如友盟、TalkingData、Firebase Analytics）
  • 广告类 SDK（如穿山甲、优量汇、AdMob）
  • 崩溃监控类 SDK（如 Bugly、Sentry）
  • 账号与支付类 SDK（如微信、支付宝、TapTap 登录）
  • 推送类 SDK（如极光、个推）

因此，不存在向任何第三方共享、转让或委托处理你个人信息的情形，也不存在数据出境。

本游戏使用开源游戏引擎 Godot Engine 开发。该引擎本身不包含任何数据收集或上报功能，同样不会收集你的信息。

六、信息的共享、转让与公开披露

由于本游戏不收集任何个人信息，我们不存在向第三方共享、转让或公开披露你个人信息的行为。

若未来版本引入账号、内购、广告或联网功能，我们会在功能上线前更新本政策，明确说明新增收集的信息类型、用途与共享对象，并依法重新征得你的同意。

七、数据安全

由于本游戏不收集也不传输个人信息，不存在个人信息在传输或服务器端泄露的风险。存档数据的安全性由你的设备与操作系统负责。

我们建议你：为设备设置锁屏密码；不要将设备交由他人随意使用；在更换或出售设备前清除应用数据。

八、未成年人保护

本游戏内容为修仙题材的文字与图形冒险，不含暴力血腥、赌博或色情内容，适合全年龄段用户。

若你是未满 14 周岁的儿童，请在监护人陪同下阅读本政策，并在取得监护人同意后使用本游戏。由于本游戏不收集任何个人信息，也不含内购与广告，不存在诱导消费或信息泄露的风险。

监护人如对本游戏有任何疑问，欢迎通过第十节的方式联系我们。
